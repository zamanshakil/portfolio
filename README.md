# Shakil Zaman | Portfolio

Personal portfolio site: **[shakilzaman.com](https://shakilzaman.com)**

Data, BI, and machine learning work, including research publications. Built with React and MUI.

## Run locally

```
npm install
npm start
```

Content lives in `src/assets/configs/`. Copy `.env.example` to `.env` to set the contact email and optional analytics ID.

## Deploy

```
npm run deploy
```
